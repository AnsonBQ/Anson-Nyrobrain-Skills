# 👥 Agent Profiles Directory

Welcome to the **Nyrobrain Core Workforce Staging Layer**. This directory serves as the centralized registry for your autonomous agent team profiles. 

Unlike standard static script configurations, profiles registered here are treated as **permanent, stateful corporate workers** operating inside your digital workspace company. They are designed to execute ongoing quantitative tasks, manage long-term memory logs, and enforce strict workplace operational protocols.

---

## 🚀 Automated Recruitment (Recommended)

You do **not** need to manually draft these markdown files. Nyrobrain includes a native workspace execution engine built specifically to onboard your team for you.

### How to use the automated generator:
Simply trigger your local AI agent using the specialized repository skill:

```text
/create-agents
```

**Example Prompt:**
> *"Run `/create-agents` to recruit a high-frequency trading analyst named `nyro-alpha-trader`. It needs to monitor order book liquidity, leverage the `/strategy` skill block, and enforce a maximum daily drawdown constraint of 1.5%."*

The engine will automatically analyze your performance constraints, generate the standardized corporate profile file, and save it directly into this directory with zero manual syntax formatting required.

---

## 📈 The Evolution Loop: Treat Agents Like Real Employees

To maximize the efficiency and accuracy of your automated company, you must **actively manage, train, and iterate on your agent team profiles** using real-world performance data.

### 🔄 The Feedback & Training Protocol:
Do not treat these files as "set-and-forget" text documents. After running each pipeline iteration, strategy backtest, or live execution loop, audit your agent’s decisions:
1. **Analyze the Loop Output:** Did the agent follow workspace protocols efficiently? Did it experience drift or execution gaps?
2. **Update the Profile (Performance Review):** Ask your agent: `"Review the latest loop logs and use /create-agents to optimize the profile configurations for nyro-alpha-trader to v1.0.5."`
3. **Build Compounded Workspace Memory:** Documenting institutional knowledge directly back into their profile file builds a persistent memory foundation, making the agent sharper, faster, and highly calibrated to your specific execution rules.
